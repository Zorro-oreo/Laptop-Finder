# Student Laptop Finder

SW302 – User Interface Development, Assignment 2 (JavaScript & Tailwind CSS 4)
Author: Youssef Amgad Abdelrahman

GitHub repo: (https://github.com/Zorro-oreo/Laptop-Finder)

## Install
```bash
npm install
```

## Build CSS
```bash
npm run build     # one-off build → dist/output.css
npm run watch     # rebuild on change while developing
```

## Run
Open the folder in VS Code and start **Live Server** on `index.html`
(`fetch()` does not work when pages are opened directly as files).
